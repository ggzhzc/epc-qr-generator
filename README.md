# 快速部署指南

## 🚀 一键部署到各平台

### Cloudflare Pages (推荐)
1. 下载 `epc-qr-generator-static.zip`
2. 访问 [Cloudflare Pages](https://pages.cloudflare.com/)
3. 点击 "Create a project" → "Upload assets"
4. 上传ZIP文件，项目名称填写 `epc-qr-generator`
5. 点击 "Deploy site"

### Netlify
1. 下载 `epc-qr-generator-static.zip`
2. 访问 [Netlify](https://www.netlify.com/)
3. 直接拖拽ZIP文件到部署区域
4. 等待部署完成

### Vercel
1. 下载 `epc-qr-generator-static.zip`
2. 访问 [Vercel](https://vercel.com/)
3. 点击 "Add New..." → "Project"
4. 上传ZIP文件或解压后上传文件夹

## ✅ 部署后验证

部署完成后，访问您的网站并测试以下功能：
1. 输入收款人姓名、IBAN和金额
2. 查看QR码是否正确生成
3. 测试下载QR码功能
4. 验证表单验证是否正常工作

## 🔧 自定义域名

大多数平台都支持自定义域名：
- Cloudflare Pages: 在项目设置中添加自定义域名
- Netlify: 在 Domain settings 中配置
- Vercel: 在项目设置的 Domains 部分添加
